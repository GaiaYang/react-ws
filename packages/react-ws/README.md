# react-ws-context

[![npm version](https://img.shields.io/npm/v/react-ws-context.svg)](https://www.npmjs.com/package/react-ws-context)
[![npm downloads](https://img.shields.io/npm/dm/react-ws-context.svg)](https://www.npmjs.com/package/react-ws-context)

`react-ws-context` is a React WebSocket connection layer with separate APIs for actions, connection state, and WebSocket events.

## Features

- Reconnect with backoff, jitter, and max delay
- Liveness detection
- Outgoing message queue
- React 18+
- TypeScript support

## Requirements

- React 18 or newer
- A runtime with `globalThis.WebSocket`
