# AGENTS

避免過度設計。先沿用 WebSocket 既有的介面與行為；做不到時，只補連線生命週期缺的那一塊，不另做一套說法。

只做一條 WebSocket 的連線與生命週期。不定義應用層協定，也不加沒被提出的能力。

不把 `WebSocket` 實例交出去。送出、關閉、心跳由套件執行。socket 事件沿用原本的事件物件；不是 socket 事件的失敗另用一個事件。

只依賴 ECMAScript 與 `globalThis.WebSocket`。計時算執行環境。不使用其他平台 API，也不讀網路狀態或前後景。

`src/core` 是與框架無關的連線層，方便單獨測試，也讓以後的框架綁定與 `src/react` 同層。React 綁定只放 `src/react`。進入點可以標 `"use client"`。

重構維持上述邊界與公開契約，不順便改對外行為。行為以既有測試與 changelog 為準。

連線若會悄悄壞掉，在上述範圍內修正。多種做法都守住時，選不改既有預設、公開型別改動最少的那一種，並寫明原因。
